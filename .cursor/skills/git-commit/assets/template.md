# Git Commit — 출력 템플릿

커밋 메시지를 출력할 때 아래 형식을 그대로 사용한다.
커밋을 직접 실행하지 않고 메시지 텍스트만 출력한다.

---

```
{타입}: {이슈번호} {한 줄 요약}

- {변경사항 1}
- {변경사항 2}
- {변경사항 N}
```

---

## 작성 규칙 요약

| 요소 | 필수 여부 | 비고 |
|------|-----------|------|
| 타입 | 필수 | `references/api.md` 타입 목록 참고 |
| 이슈번호 | 선택 | 없으면 생략 |
| 한 줄 요약 | 필수 | 50자 이내, 명령형 한국어 |
| 빈 줄 | 필수 | 한 줄 요약과 변경사항 목록 사이 |
| 변경사항 목록 | 필수 | 1개 이상, `-` 로 시작 |
