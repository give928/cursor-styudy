> **작성자:** DB Inc. 백엔드 개발팀

## 한 줄 요약

고객이 보험금을 청구(클레임)하면, **시스템이 자동으로 고객 등급에 맞는 할인율을 계산해 함께 기록**하는 기능이 추가되었습니다.

---

## 무엇이 바뀌었나요?

### 추가된 기능

#### 1. 클레임(보험금 청구) 접수
고객이 사고 발생 후 보험금을 청구하면 시스템에 접수 내역이 저장됩니다.

- 접수된 클레임은 즉시 **'접수 완료'** 상태로 등록됩니다.
- 접수 시 사고 일시, 청구 금액, 계약 정보가 함께 기록됩니다.
- **동일 계약에 처리 중인 클레임이 이미 있으면 중복 접수가 불가합니다.**

#### 2. 고객 등급별 할인율 자동 적용
클레임 접수 시점에 고객 등급을 조회해, 해당 등급에 맞는 할인율을 **자동으로 계산하여 저장**합니다.

| 고객 등급 | 할인율 | 대상 고객 |
|:---------:|:------:|-----------|
| VIP | 10% | 가입 5년 이상, 무사고, 연 보험료 1,000만원 이상 |
| GOLD | 5% | 가입 3년 이상, 무사고 |
| SILVER | 3% | 가입 1년 이상 |
| BASIC | 0% | 그 외 일반 고객 |

> **중요:** 할인율은 **접수 시점의 등급이 고정**됩니다. 이후 고객 등급이 변경되더라도 이미 접수된 클레임의 할인율은 소급 적용되지 않습니다.

#### 3. 클레임 처리 이력 자동 기록
클레임이 접수될 때마다 **변경 이력이 시스템에 자동으로 기록**됩니다. 추후 감사(Audit) 또는 민원 발생 시 접수 당시 정보를 정확히 조회할 수 있습니다.

---

## 클레임 처리 흐름

```
고객 사고 발생
      │
      ▼
 클레임 접수 (자동으로 할인율 계산·저장)
      │
      ▼
   심사 진행
      │
      ├──▶ 승인 완료 → 고객에게 이메일·문자 알림 발송 (예정)
      │
      └──▶ 거절 → 거절 사유 기록
```

---

## 운영팀 참고 사항

| 항목 | 내용 |
|------|------|
| 중복 접수 방지 | 동일 계약에 '접수 완료' 상태 클레임이 존재하면 추가 접수 불가 |
| 할인율 소급 불가 | 등급 변경이 생겨도 기존 클레임 할인율은 변경되지 않음 |
| 접수 가능 시간 | 24시간 365일 (시스템 점검 시간 제외) |
| 데이터 보관 | 접수 이력은 감사 로그에 영구 보관 |
